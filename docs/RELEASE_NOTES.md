# v0.1.0 — A Stone Age Adventure

First playable comic interpretation of B.C.'s Quest for Tires.

- Nine chapters with rocks, branches, turtles, bird-assisted lava crossing, cliff jump, volcanic boulders, dinosaur and rescue.
- New outlined illustrations, parallax scenery and synthesized sound/music.
- Keyboard, touch and standard gamepad mappings; practice tools and separate audio controls.
- Twelve passing tests, including complete simulation-level playthroughs in both input modes.

Play: https://andredp-developer.github.io/bc-quest-for-tires/

itch.io: https://fabrulana.itch.io/bc-quest-for-tires

The attached ZIP is ready for an HTML5 host, with index.html at its root. This is an unofficial fan interpretation using new physics and obstacle spacing. It is not a C64 emulator or cycle-exact port. Physical slopes and alternating two-player mode are not included in this first version.
